# 🦠 COVID-19 Data Analysis

## 📊 Project Overview
Analyzed global COVID-19 dataset to understand spread and impact across countries.

## 🔍 Key Insights
- **Total Cases:** Cases increased rapidly from Jan to July 2020
- **Top Affected:** USA, Brazil, India had highest confirmed cases
- **Deaths vs Recovered:** High recovery rate observed globally
- **Peak Period:** March-July 2020 was critical phase

## 🛠️ Tools Used
- Python, Pandas, Matplotlib
- Google Colab, GitHub

## 📈 Visualizations
1. World Total Cases Over Time
2. Top 10 Most Affected Countries
3. Deaths vs Recovered Comparison
